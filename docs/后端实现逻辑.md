### 1.5 后端的具体逻辑是什么

后端接口由 `module-auth` 模块提供（当前 server 为骨架阶段，代码待开发；以下为结合数据库设计文档推导的实现逻辑）：

```plain
POST /api/admin/v1/auth/sms-code
├─ 1. 接收 phone、scene，校验手机号格式与 scene 枚举合法性
├─ 2. 发送频控：同一手机号 60 秒内不允许重复发送（可借助 Redis 或查询最近一条验证码记录实现）
├─ 3. 生成 6 位随机数字验证码
├─ 4. 写入 auth_sms_code 表（验证码不存明文）：
│      ├─ 手机号密文 = 加密后的手机号
│      ├─ 手机号HMAC  = 手机号的 HMAC 值（用于按手机号查询/关联）
│      ├─ 使用场景   = 'LOGIN'
│      ├─ 验证码哈希 = 验证码的哈希值
│      ├─ 过期时间   = 当前时间 + 5 分钟
│      ├─ 发送IP     = 客户端 IP
│      └─ 创建时间   = 当前时间
├─ 5. 调用短信服务商发送验证码短信（发送失败则不返回成功）
└─ 6. 返回统一响应 { code, message, data }，响应中绝不返回验证码明文
```

验证码本身只在第 5 步发给用户手机，库中只存哈希；后续 `loginBySms()` 校验时同样对用户输入做哈希比对——校验通过回写“使用时间”（标记已消费），失败累计“验证失败次数”。

具体实现代码（server/pelvic-modules/module-auth/src/main/java/com/pelvic/auth/）：

```java
// service/SmsCodeService.java（核心方法，60 秒频控 + 只存哈希 + 5 分钟过期）
public void send(String phone, String scene, String ip) {
    if (phone == null || !phone.matches("^1[3-9]\\d{9}$")) {
        throw new BizException("请输入正确的手机号格式");
    }
    if (scene == null || !SCENES.contains(scene)) {
        throw new BizException("无效的使用场景");
    }
    String hmac = hmacSigner.sign(phone);
    AuthSmsCode latest = smsCodeMapper.selectLatest(hmac, scene);
    if (latest != null && latest.getCreateTime() != null
            && latest.getCreateTime().plusSeconds(resendIntervalSeconds).isAfter(LocalDateTime.now())) {
        throw new BizException("验证码发送过于频繁，请稍后再试");   // 60 秒频控
    }
    String code = String.format("%06d", RANDOM.nextInt(1_000_000));   // 6 位随机码
    AuthSmsCode entity = new AuthSmsCode();
    entity.setPhoneCipher(aesEncryptor.encrypt(phone));   // 手机号密文
    entity.setPhoneHmac(hmac);
    entity.setScene(scene);
    entity.setCodeHash(HashUtil.sha256Hex(code));         // 验证码只存哈希
    entity.setExpireTime(LocalDateTime.now().plusMinutes(codeTtlMinutes));   // 5 分钟
    entity.setSendIp(ip);
    smsCodeMapper.insert(entity);
    smsSender.send(phone, code);   // ConsoleSmsSender：开发期打印到日志，生产接真实短信服务商
}

// mapper/AuthSmsCodeMapper.java：消费防重放（原子 UPDATE）
@Update("UPDATE auth_sms_code SET 使用时间 = NOW() WHERE 验证码ID = #{id} AND 使用时间 IS NULL")
int markUsed(Long id);

// controller/AuthController.java
@PostMapping("/sms-code")
public Result<Void> sendSmsCode(@Valid @RequestBody SmsCodeRequest request, HttpServletRequest httpRequest) {
    smsCodeService.send(request.getPhone(), request.getScene(), clientIp(httpRequest));
    return Result.ok();
}
```

## 2.登录实现-LoginVue.vue

功能概述：用户在登录页选择“密码登录”或“短信验证码登录”，点击“登 录”按钮（或密码框内按回车）触发登录；前端校验通过后按登录方式调用密码登录或短信登录接口，后端完成身份校验、创建会话并返回 token 与用户信息。

### 2.5 后端的具体逻辑是什么

后端接口由 `module-auth` 模块提供（当前 server 为骨架阶段，代码待开发；以下为结合数据库设计文档推导的实现逻辑）。

```plain
POST /api/admin/v1/auth/login/password（密码登录）
├─ 1. 根据手机号HMAC在 account 表中查询该账户是否存在
│    ├─ if 不存在：返回友好错误提示“该用户不存在！”（写 sys_login_log：登录结果=FAILED）
│    └─ if 存在：校验账号状态（PENDING/DISABLED/CANCELLED 不可登录）
│        └─ 2. 按账号ID取 account_credential（一个账号最多一条网页密码凭证），比对密码哈希
│            ├─ if 锁定截止时间未过：返回“账号已锁定，请稍后再试”
│            ├─ if 哈希不匹配：连续失败次数+1（达到阈值则写锁定截止时间），
│            │                 写 sys_login_log（登录结果=FAILED），返回“密码不正确！”
│            └─ if 正确：连续失败次数清零，进入“登录成功”公共流程
```

```plain
POST /api/admin/v1/auth/login/sms（短信验证码登录）
├─ 1. 按手机号HMAC在 auth_sms_code 表中查最新一条 scene='LOGIN' 的记录
│    ├─ if 不存在 或 已过期（过期时间<当前时间）：返回“验证码已过期，请重新获取”
│    ├─ if 验证失败次数已达上限：返回“验证码错误次数过多，请重新获取”
│    ├─ if 哈希比对不匹配：验证失败次数+1，写 sys_login_log（FAILED），返回“验证码错误！”
│    └─ if 匹配：回写 使用时间（标记该验证码已使用，防重放）
│        └─ 2. 按手机号HMAC在 account 表中查询该账户是否存在（不存在说明是初次登录）
│            ├─ if 存在：进入“登录成功”公共流程
│            └─ if 不存在（初次登录）：
│                ├─ 1. 新建账号：account 表插入一条新数据（注册来源=WEB，写入手机号密文/手机号HMAC）
│                └─ 2. 给账号授权：sys_user_role 表插入一条新数据（默认角色）
```

```plain
“登录成功”公共流程（两种登录方式共用）
├─ 1. 更新 account.最后登录时间
├─ 2. 创建会话：auth_session 表插入一条（客户端类型=WEB_ADMIN，保存 AccessToken哈希/RefreshToken哈希、过期时间）
├─ 3. 查询用户角色与权限码（sys_user_role / sys_role_permission / sys_permission）
├─ 4. 写 sys_login_log（登录结果=SUCCESS，登录方式=PASSWORD 或 SMS_CODE，记录 IP、UserAgent）
└─ 5. 返回统一响应 { code, message, data }（见下方“响应数据”）
```

具体实现代码（server/pelvic-modules/module-auth/src/main/java/com/pelvic/auth/）：

```java
// service/LoginService.java：密码登录（校验账号状态 → 密码哈希比对 → 失败次数/锁定）
public LoginResponse loginByPassword(String phone, String password, String ip, String userAgent) {
    Account account = accountMapper.selectByPhoneHmac(hmacSigner.sign(phone));
    if (account == null) {
        logLogin(null, "PASSWORD", false, "该用户不存在", ip, userAgent);
        throw new BizException("该用户不存在！");
    }
    checkStatus(account);   // 账号状态非 NORMAL → "账号不可用，请联系管理员"
    AccountCredential credential = credentialMapper.selectByAccountId(account.getId());
    if (credential == null) {
        throw new BizException("该账号未设置登录密码，请使用短信验证码登录");
    }
    if (credential.getLockedUntil() != null && credential.getLockedUntil().isAfter(LocalDateTime.now())) {
        throw new BizException("账号已锁定，请稍后再试");
    }
    if (password == null || !passwordEncoder.matches(password, credential.getPasswordHash())) {
        int fails = credential.getFailCount() == null ? 0 : credential.getFailCount();
        fails += 1;
        LocalDateTime lockedUntil = fails >= PWD_LOCK_THRESHOLD   // 5 次失败
                ? LocalDateTime.now().plusMinutes(PWD_LOCK_MINUTES) : null;   // 锁 30 分钟
        credentialMapper.updateFail(account.getId(), fails, lockedUntil);
        logLogin(account.getId(), "PASSWORD", false, "密码不正确", ip, userAgent);
        throw new BizException("密码不正确！");
    }
    credentialMapper.updateFail(account.getId(), 0, null);
    return doLoginSuccess(account, "PASSWORD", ip, userAgent);
}

// service/LoginService.java：短信登录（过期/失败次数校验 → 原子消费 → 初次登录建号+默认角色）
@Transactional(rollbackFor = Exception.class)
public LoginResponse loginBySms(String phone, String smsCode, String ip, String userAgent) {
    String hmac = hmacSigner.sign(phone);
    AuthSmsCode sms = smsCodeMapper.selectLatest(hmac, "LOGIN");
    if (sms == null || sms.getExpireTime() == null || sms.getExpireTime().isBefore(LocalDateTime.now())
            || sms.getUsedTime() != null) {
        throw new BizException("验证码已过期，请重新获取");
    }
    if (sms.getFailCount() != null && sms.getFailCount() >= MAX_SMS_FAIL) {   // 5 次
        throw new BizException("验证码错误次数过多，请重新获取");
    }
    if (!HashUtil.sha256Hex(smsCode).equals(sms.getCodeHash())) {
        smsCodeMapper.incrFailCount(sms.getId());
        throw new BizException("验证码错误！");
    }
    if (smsCodeMapper.markUsed(sms.getId()) == 0) {   // 原子消费防重放
        throw new BizException("验证码已被使用，请重新获取");
    }
    Account account = accountMapper.selectByPhoneHmac(hmac);
    if (account == null) {
        account = createAccount(phone, hmac);                       // 注册来源=WEB，写入手机号密文/HMAC
        accountMapper.grantDefaultDoctorRole(account.getId());      // 默认医生角色（角色ID=2）
    } else {
        checkStatus(account);
    }
    return doLoginSuccess(account, "SMS_CODE", ip, userAgent);
}

// service/LoginService.java：“登录成功”公共流程
private LoginResponse doLoginSuccess(Account account, String loginType, String ip, String userAgent) {
    accountMapper.updateLastLoginTime(account.getId());
    String accessToken = TokenUtil.randomToken();        // 32 字节随机不透明 token
    String refreshToken = TokenUtil.randomToken();
    AuthSession session = new AuthSession();             // 只存 token 哈希
    session.setAccountId(account.getId());
    session.setClientType("WEB_ADMIN");
    session.setAccessTokenHash(TokenUtil.hash(accessToken));
    session.setRefreshTokenHash(TokenUtil.hash(refreshToken));
    session.setExpireTime(LocalDateTime.now().plusSeconds(securityProperties.getTokenTtlSeconds()));
    sessionMapper.insert(session);
    UserInfo userInfo = authUserLoader.load(account.getId());   // 角色 + 权限码
    // …… 组装 LoginResponse（userId=D001 格式 / roleCode / permissions）
    logLogin(account.getId(), loginType, true, null, ip, userAgent);   // 写 sys_login_log
    return response;
}

// service/AuthServiceImpl.java：请求鉴权（AuthInterceptor 每次请求调用）
public AuthContext parse(String accessToken) {
    AuthSession session = sessionMapper.selectByAccessHash(TokenUtil.hash(accessToken));
    if (session == null || session.getRevokeTime() != null) return null;
    if (session.getExpireTime() == null || session.getExpireTime().isBefore(LocalDateTime.now())) return null;
    Account account = accountMapper.selectById(session.getAccountId());
    if (account == null || !"NORMAL".equals(account.getStatus())) return null;
```

```java
// controller/SystemController.java
@GetMapping("/users")
public Result<PageResult<UserRowResp>> users(
        @RequestParam(required = false) String keyword,
        @RequestParam(required = false) String role,
        @RequestParam(defaultValue = "1") long page,
        @RequestParam(defaultValue = "30") long size) {
    return Result.ok(userListService.list(keyword, role, page, size));
}

// service/UserListService.java：数据范围服务端强制，手机号解密脱敏
public PageResult<UserRowResp> list(String keyword, String role, long page, long size) {
    AuthContext ctx = AuthContext.require();
    String effectiveRole = ("patient".equals(role) || "doctor".equals(role)) ? role : null;
    if (!ctx.isAdmin()) {
        effectiveRole = "patient";   // 普通医生仅患者列表（不信任前端 role 参数）
    }
    String kw = (keyword == null || keyword.isBlank()) ? null : keyword.trim();
    long offset = (Math.max(page, 1) - 1) * size;
    long total = systemUserMapper.countUsers(effectiveRole, kw);
    List<UserRow> rows = systemUserMapper.selectUsers(effectiveRole, kw, offset, size);
    List<UserRowResp> records = rows.stream().map(this::toResp).toList();
    return PageResult.of(total, records);
}
// toResp：手机号 AES 解密后 138****0000 脱敏，解密失败返回 "****"

// mapper/SystemUserMapper.java：患者/医生 UNION 后统一筛选分页（动态 SQL 骨架）
String UNION = "SELECT p.患者编号 AS id, p.姓名 AS name, 'patient' AS role, a.手机号密文 AS phoneCipher "
        + "FROM patient p JOIN account a ON a.账号ID = p.账号ID WHERE p.是否删除 = 0 "
        + "UNION ALL "
        + "SELECT CONCAT('D', LPAD(d.编号, 3, '0')) AS id, d.姓名 AS name, 'doctor' AS role, a.手机号密文 AS phoneCipher "
        + "FROM doctor d JOIN account a ON a.账号ID = d.账号ID";

@Select("<script>"
        + "SELECT t.id, t.name, t.role, t.phoneCipher FROM (" + UNION + ") t "
        + "<where>"
        + "  <if test='role != null'> AND t.role = #{role} </if>"
        + "  <if test='keyword != null'> AND (t.id LIKE CONCAT('%', #{keyword}, '%') OR t.name LIKE CONCAT('%', #{keyword}, '%')) </if>"
        + "</where>"
        + " ORDER BY t.id LIMIT #{offset}, #{size}"
        + "</script>")
List<UserRow> selectUsers(@Param("role") String role, @Param("keyword") String keyword,
                          @Param("offset") long offset, @Param("size") long size);
// countUsers 同条件 COUNT(*) 子查询版本
```

```java
// service/DoctorService.java：移除医生
@Transactional(rollbackFor = Exception.class)
public void remove(String doctorId) {
    AuthContext ctx = requireAdmin("仅管理员可移除医生");
    long doctorNo = parseDoctorNo(doctorId);
    Doctor doctor = doctorMapper.selectByNo(doctorNo);
    if (doctor == null) {
        throw new BizException("医生不存在");
    }
    if (doctor.getAccountId().equals(ctx.getAccountId())) {
        throw new BizException("不能移除当前登录账号");
    }
    // 逻辑移除：仅更新审核状态与原因（其余字段为 null，MP 默认不更新）
    Doctor update = new Doctor();
    update.setId(doctor.getId());
    update.setAuditStatus("审核未通过");
    update.setAuditReason("管理员移除");
    doctorMapper.updateById(update);
    // 停用账号并撤销该医生全部登录会话
    doctorMapper.disableAccount(doctor.getAccountId());   // account.账号状态 → DISABLED
    authSessionMapper.revokeByAccountId(doctor.getAccountId());   // auth_session 写撤销时间
    // 写 sys_operate_log（操作类型=DELETE）
    writeOperateLog(ctx.getAccountId(), "DELETE", doctorId, "DELETE", CREATE_URI + "/" + doctorId);
}

// controller/DoctorController.java
@DeleteMapping("/{doctorId}")
@RequireRole("ADMIN")
public Result<Void> remove(@PathVariable String doctorId) {
    doctorService.remove(doctorId);
    return Result.ok();
}
```

```java
private String subtitle(TrainingContent content) {
    if (content == null) return "训练 · —";
    String form = switch (content.getContentType() == null ? "" : content.getContentType()) {
        case "视频" -> "视频"; case "音频" -> "音频"; case "文本" -> "图文"; default -> "训练";
    };
    Integer seconds = content.getDurationSeconds();
    if (seconds == null) return form + " · —";
    int minutes = seconds <= 0 ? 0 : (seconds + 59) / 60;
    return form + " · " + minutes + "分钟";
}
```

```java
/** 提交导出任务，返回 taskId；审计日志同步写入 sys_operate_log */
public String submit(String reportType, Map<String, Object> params) {
    AuthContext context = AuthContext.require();
    String type = ReportDataService.normalizeType(reportType);   // 空/未知类型校验
    String taskId = UUID.randomUUID().toString();
    ExportTaskStatus status = new ExportTaskStatus();
    status.setTaskId(taskId);
    status.setReportType(type);
    status.setStatus(ExportTaskStatus.PROCESSING);
    tasks.put(taskId, status);           // 内存任务表（TODO：生产持久化到 DB）
    writeOperateLog(context.getAccountId(), type, params);   // sys_operate_log（EXPORT 审计）
    executor.submit(() -> runExport(context, taskId, type, query));   // 单线程执行器
    return taskId;
}

/** 异步执行：全量查询 → EasyExcel 动态表头写文件 → 更新任务状态 */
private void runExport(AuthContext context, String taskId, String type, Map<String, Object> params) {
    ExportTaskStatus status = tasks.get(taskId);
    AuthContext.set(context);   // 异步线程无请求上下文，需手动传递
    try {
        Map<String, Object> query = new LinkedHashMap<>(params);
        query.put("page", 1);
        query.put("size", 100000);   // 全量复用报表查询（与页面同口径）
        List<Map<String, Object>> rows = reportDataService.page(type, query).getRecords();

        Columns columns = columns(type);          // 每类报表的 KEYS + 中文表头常量
        List<List<String>> head = new ArrayList<>();
        for (String header : columns.headers) {
            head.add(List.of(header));            // EasyExcel 动态表头
        }
        List<List<Object>> data = new ArrayList<>();
        for (Map<String, Object> row : rows) {
            List<Object> line = new ArrayList<>();
            for (String key : columns.keys) {
                line.add(row.get(key));           // 按列定义顺序铺平
            }
            data.add(line);
        }
        File directory = new File(exportDir);     // pelvic.report.export-dir（默认 ./export）
        if (!directory.exists() && !directory.mkdirs()) {
            throw new IOException("无法创建导出目录：" + directory.getAbsolutePath());
        }
        String fileName = type + "_" + LocalDateTime.now().format(FILE_TIME)
                + "_" + taskId.substring(0, 8) + ".xlsx";
        EasyExcel.write(new File(directory, fileName)).head(head).sheet("数据").doWrite(data);

        status.setFileName(fileName);
        status.setDownloadUrl("/api/admin/v1/report/export-task/" + taskId + "/download");
        status.setStatus(ExportTaskStatus.SUCCESS);
    } catch (Exception e) {
        status.setStatus(ExportTaskStatus.FAILED);
        status.setErrorMessage(e.getMessage() == null ? "导出失败" : e.getMessage());
    } finally {
        AuthContext.clear();
    }
}
```

```javascript
const oldPwd = ref(''); const newPwd = ref(''); const confirmPwd = ref(''); const errMsg = ref('')

function onOk() {
  const o = oldPwd.value.trim()
  const n = newPwd.value.trim()
  const c = confirmPwd.value.trim()

  if (!o) return (errMsg.value = '请输入原密码')
  if (o !== currentPwd) return (errMsg.value = '原密码不正确')   // 原型本地比对，联调后由后端校验
  if (!n) return (errMsg.value = '请输入新密码')

  if (n !== c) return (errMsg.value = '两次输入的新密码不一致')

  currentPwd = n
  modalVisible.value = false
  void changePassword({ oldPassword: o, newPassword: n })
  ElMessage.success('密码修改成功（原型占位）')
}
```

```plain
│      └─ 匹配 → 更新 密码哈希（newPassword 加盐哈希）与 密码更新时间
├─ 4. （可选）撤销该账号其他 auth_session，强制重新登录
└─ 5. 返回统一响应
```

具体实现代码（server/pelvic-modules/module-auth/src/main/java/com/pelvic/auth/）：

```java
// service/AccountSecurityService.java：修改密码
@Transactional(rollbackFor = Exception.class)
public void changePassword(String oldPassword, String newPassword) {
    AuthContext ctx = AuthContext.require();
    AccountCredential credential = credentialMapper.selectByAccountId(ctx.getAccountId());
    if (credential == null) {
        throw new BizException("该账号未设置登录密码");
    }
    if (!passwordEncoder.matches(oldPassword, credential.getPasswordHash())) {   // BCrypt 比对
        credentialMapper.updateFail(ctx.getAccountId(),
                (credential.getFailCount() == null ? 0 : credential.getFailCount()) + 1, null);
        throw new BizException("原密码不正确");
    }
    credentialMapper.updatePassword(ctx.getAccountId(), passwordEncoder.encode(newPassword));
    // 修改密码后撤销该账号其他会话，强制重新登录
    sessionMapper.revokeOtherSessions(ctx.getAccountId(), ctx.getSessionId());
}

// mapper/AccountCredentialMapper.java
@Update("UPDATE account_credential SET 密码哈希 = #{hash}, 密码更新时间 = NOW() WHERE 账号ID = #{accountId}")
int updatePassword(Long accountId, String hash);

// mapper/AuthSessionMapper.java
@Update("UPDATE auth_session SET 撤销时间 = NOW() WHERE 账号ID = #{accountId} AND 会话ID <> #{sessionId} AND 撤销时间 IS NULL")
int revokeOtherSessions(Long accountId, Long sessionId);

// controller/AuthController.java
@PostMapping("/change-password")
public Result<Void> changePassword(@Valid @RequestBody ChangePasswordRequest request) {
    accountSecurityService.changePassword(request.getOldPassword(), request.getNewPassword());
    return Result.ok();
}
```

| auth_session | （可选）撤销其他会话 |

请求方法：POST；无请求体（由请求头 `Authorization: Bearer <token>` 识别会话；refresh token 走 httpOnly Cookie）。

### 28.5 后端的具体逻辑是什么

```plain

├─ 2. 撤销会话：auth_session 表写撤销时间（token 立即失效）

```
