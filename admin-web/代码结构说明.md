# 代码结构说明（admin-web · 网页后台）

## 1. 文档说明

- 生成时间：2026-11-15
- 目标工程：`pelvic-rehab/admin-web`
- 技术栈：Vue 3 + TypeScript + Vite + Vue Router 4 + Pinia + Element-Plus + ECharts + Axios
- 生成依据：
  - 原型图：`ui/prototype/web-interactive-prototype/index.html`（全部 16 个页面）
  - 功能文档：`docs/功能文档-表格版.xlsx`（"网页后台功能文档" sheet）

## 2. 项目概览

- 网页后台（PC 管理端），接口前缀 `/api/admin/v1/**`（后端 Spring Boot，开发环境经 vite 代理转发到 `http://localhost:8080`，见 `vite.config.ts`）
- 启动方式：
  1. `npm install`（安装依赖）
  2. `npm run dev`（开发模式，默认 http://localhost:5173）
  3. 构建：`npm run build`
- 登录：原型"密码登录 / 短信验证码登录"双模式（`src/views/login/LoginView.vue`）；当前为占位登录，默认以医生身份进入用户管理
- 权限：侧边菜单四入口（用户管理 / 数据总览 / 报表总览 / 个人主页）；管理员身份下用户管理页多出"角色筛选 + 添加医生"（原型 01-1 与 01-2 的差异）

## 4. 代码结构（哪段代码对应哪个模块）

### 4.1 启动与骨架

- `src/main.ts`：加载顺序 = 全局样式 → Element-Plus（中文语言包）→ Pinia → Router → 挂载 `App.vue`。**要改全局插件/依赖时看这里**
- `src/router/index.ts`：**所有页面地址与对应组件在这里登记**，`meta.proto` 标明原型图编号；页面标题由路由守卫统一写进浏览器标题

### 4.2 布局与导航

- `src/layouts/DefaultLayout.vue`：左侧深色导航（用户管理/数据总览/报表总览/个人主页）+ 顶栏标题 + 内容区
  - 菜单项改文案/加菜单：改本文件 `<el-menu-item>` 与路由表
  - 菜单高亮规则：`activeMenu` 计算属性按路由前缀归一（如 `/user/patient/1` 高亮"用户管理"）

### 4.3 请求层与登录态

- `src/api/request.ts`：
  - `baseURL` 取环境变量 `VITE_API_BASE`
  - 请求拦截器：注入 `Authorization: Bearer <token>`
  - 响应拦截器：401 → 清 token 跳登录；其余错误统一 `ElMessage` 提示
- `src/utils/auth.ts`：token 内存存取（架构文档约定 refresh token 走 httpOnly Cookie，联调时在此扩展）
- `src/api/` 各文件：按后端模块分文件（auth / system / report），**所有接口函数都集中在这里，页面不直接 import axios**

### 4.4 状态管理

- `src/stores/user.ts`：当前用户、`isAdmin`（管理员判断，决定用户管理页展示 01-1 还是 01-2 形态）、`hasPermission`（按钮权限，后续接 `v-permission`）

### 4.5 公共能力

- `src/composables/useTablePage.ts`：列表页"筛选 + 分页 + 回顶"通用逻辑。页面 01/04/07 系列都调用它：传入数据源与过滤函数，返回 `pagedRows / total / currentPage / resetPage`
- `src/components/ChartCard.vue`：ECharts 卡片封装（标题/副标题/图例插槽/tip），统一处理图表 init/resize/dispose
- `src/styles/index.css`：原型视觉（卡片、标签、表格、提示框）与 Element 主题色 `#1E9E8F` 覆盖。**样式与原型不一致时先看这里，再看页面内 `<style scoped>`**

### 4.6 业务模块 ↔ 代码对照

| 业务模块 | 页面文件 | 接口文件 | 关键交互代码位置 |
|----------|----------|----------|------------------|

## 6. 请求与数据流

### 6.1 调用链路

```
页面（views/*） → api 函数（api/*.ts） → axios 实例（api/request.ts） → 后端 /api/admin/v1/**
                    ↑ token 注入（utils/auth.ts）       ↑ 401/错误统一处理
```

### 6.2 mock 数据与替换步骤

当前所有页面数据为本地 mock（原型占位数据），**每处 mock 数据上方都有 `// TODO: 替换为接口数据` 注释**，集中在各页面 `<script setup>` 顶部常量（如 `allUsers`、`allRows`、`records`）。替换步骤：

1. 在对应 `api/*.ts` 中找到已预留的接口函数（函数名与注释已按业务命名）
2. 将接口函数里的 `// TODO: 联调后端接口` 路径补全为真实后端路径
3. 页面内：把 mock 常量替换为 `ref` + `onMounted` 调用接口函数，删除原 mock 数据块
4. 同步更新本说明文档第 8 节，把已完成的 TODO 移除

### 6.3 登录鉴权与字典

- 登录：`api/auth.ts`（密码/短信双模式 + 发送验证码）
- 登录态：`stores/user.ts`；token 在 `utils/auth.ts`（内存）
- 字典/枚举：原型中的下拉选项（如盆底视诊、特殊检查、量表清单）目前以常量形式写在对应页面文件内（如 `PatientDetailView.vue` 的 `inspectionFields`、`PatientDataDetailView.vue` 的 `SCALES`），后续接入 `stores/dict.ts` 字典缓存时统一迁移

## 7. 常见问题定位指南

| 现象 | 先看哪里 | 处理思路 |
|------|----------|----------|
| 页面打不开 / 显示 404 | `src/router/index.ts` | 检查路由 path 与 views 文件是否存在、import 路径是否正确 |
| 侧边菜单不显示某页/高亮错误 | `src/layouts/DefaultLayout.vue` | 菜单项是否添加；`activeMenu` 前缀匹配是否覆盖该路由 |
| 页面能开但数据是示例数据 | 页面文件内 `allUsers/allRows/records` 等常量 | 数据还是 mock，按第 6.2 节替换为接口 |
| 接口报 401 / 登录失效跳登录 | `src/api/request.ts` 响应拦截器 | 联调时补 refresh token 逻辑；token 在 `utils/auth.ts` |
| 接口报错统一弹提示 | `src/api/request.ts` | 错误提示文案在这里统一处理 |
| 样式与原型不一致 | `src/styles/index.css`（全局）→ 页面 `<style scoped>` | 主题色/卡片/标签等全局样式在 index.css；单页样式在页面文件内 |
| 点击没反应 / 跳转错误 | 页面文件内事件函数（`onXxx`）+ 第 5.2 节跳转表 | 对照跳转表查目标路由；确认按钮事件绑定 |
| 列表筛选/分页不生效 | 页面 `filterFn` + `src/composables/useTablePage.ts` | 过滤条件是否覆盖新字段；分页 pageSize 是否与原型一致（01/04=30，07 系列=10） |
| 图表不显示或尺寸异常 | `src/components/ChartCard.vue` | ChartCard 统一处理 init/resize；图表配置在 `PatientDataDetailView.vue → chartOption` |
| 想改页面标题/文案 | 页面文件模板部分 + `src/router/index.ts` 的 `meta.title` | 文案与原型图逐字对应，改动前建议先改原型图 |
| 导出按钮点了只弹提示 | 报表页 `onExport` + `src/api/report.ts` | 导出为原型占位；按架构文档走"提交导出任务 → 轮询 → 下载签名 URL" |

## 9. 后续开发指引

### 9.1 新增一个页面

1. 在 `src/views/<模块>/` 下新建页面文件，文件头部注释写明对应原型图编号与名称
2. 在 `src/router/index.ts` 中 `DefaultLayout` 的 `children` 里登记路由（path、name、component、meta.title/proto）
3. 如需出现在侧边菜单：改 `src/layouts/DefaultLayout.vue` 菜单项
4. 如页面要发请求：在 `src/api/` 对应模块文件新增接口函数
5. 更新本说明文档：第 3 节目录树、第 5.1 节对照表、第 5.2 节跳转表

### 9.2 新增/替换一个接口

1. 在 `src/api/<模块>.ts` 新增函数（路径按后端约定）
2. 页面中把 mock 常量替换为接口调用（参考第 6.2 节）
3. 更新第 8 节 TODO 清单

### 9.3 修改公共样式/组件

- 全局样式与主题色：`src/styles/index.css`
- 图表封装：`src/components/ChartCard.vue`
- 列表分页逻辑：`src/composables/useTablePage.ts`
